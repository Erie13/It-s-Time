# It's Time

Alarm Android yang baru mati setelah kamu benar-benar bangun.

Alur: alarm bunyi, geser layar (kanan = diamkan, kiri = tunda 5 menit), ketik kalimat atau jawab soal, lalu push up yang dihitung otomatis lewat kamera depan.

## Coba aplikasinya
1. Buka tab **Releases** di repository ini dan unduh file `.apk` terbaru.
2. Buka file itu di HP Android. Saat diminta, izinkan pemasangan dari sumber ini.
3. Buka It's Time, izinkan kamera dan notifikasi, tambahkan alarm, lalu tekan **Tes alarm**.

Android 14 ke atas: kalau layar alarm tidak muncul otomatis, izinkan notifikasi layar penuh di Setelan > Aplikasi > It's Time, dan matikan penghematan baterai untuk app ini.

Versi ini masih tahap uji. Kirim masukan lewat tab **Issues**.

## Build sendiri
1. Buka folder ini di Android Studio dan tunggu Gradle sync selesai.
2. Colok HP dengan USB debugging aktif, lalu tekan Run.
Atau Build > Build APK(s).

## Privasi
Kamera diproses di HP dan tidak ada gambar yang disimpan atau dikirim. Tidak ada akun, iklan, atau pelacak. Lihat `publish/privacy-policy.html`.
